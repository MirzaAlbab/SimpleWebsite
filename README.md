# SimpleWebsite

A multipage static website exercise using Bootstrap 5 Beta.

[Repository](https://github.com/MirzaAlbab/SimpleWebsite)

## Features

- Home, about, and article pages
- Registration page layout
- Custom CSS and JavaScript
- GitHub Pages deployment workflow

## Technology

HTML, CSS, JavaScript, Bootstrap 5 Beta

## Getting started

Clone the repository and serve the root directory with a local static web server. For example, with Python 3:

```bash
git clone https://github.com/MirzaAlbab/SimpleWebsite.git
cd SimpleWebsite
```

```bash
python3 -m http.server 8000
```

Open [http://localhost:8000](http://localhost:8000). Keep the relative directory layout intact so styles, scripts, and images resolve correctly.

## Development and checks

Check page navigation, responsive layouts, browser console errors, and missing assets in a browser. No root automated test runner is configured.

## Project structure

- `css/` — Stylesheets
- `img/` — Image assets
- `js/` — Browser scripts

## Project notes

The registration page is a frontend layout; a working account backend is not established by the static files.
